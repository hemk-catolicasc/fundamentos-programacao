📒 Como funciona a Agenda de Contatos

Um programa em linguagem C, explicado do jeito mais simples possível

Imagine um caderninho de telefones. Esse programa faz a mesma coisa, só que no computador: você pode anotar um contato, ver a lista toda, procurar alguém pelo nome e apagar quem não quer mais. Vamos ver cada pedaço do código sem pressa. 🙂

1 As "caixas de ferramentas"

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

Antes de começar, o programa avisa que vai usar algumas ferramentas prontas da linguagem C. Cada #include é como pegar uma caixa de ferramentas da prateleira:

  • stdio.h → ferramentas para escrever na tela e ler o que você digita.
  • stdlib.h → ferramentas gerais do sistema.
  • string.h → ferramentas para trabalhar com texto (comparar nomes, por exemplo).

2 O molde de um contato

#define MAX 100

struct Contato {
    char nome[50];
    char telefone[20];
};

Aqui o programa cria um molde do que é um contato: todo contato tem um nome e um telefone. Os números (50 e 20) dizem quantas letras cabem em cada um.

O MAX 100 define que a agenda guarda no máximo 100 contatos.

Analogia: a struct é como uma ficha em branco de cadastro, com dois campos para preencher: "Nome" e "Telefone".

3 Onde os contatos ficam guardados

struct Contato agenda[MAX];
int total = 0;

agenda é uma estante com 100 gavetas, e cada gaveta guarda uma ficha de contato.

total é um contador: ele anota quantos contatos já foram cadastrados. Começa em 0 porque, no início, a agenda está vazia.

4 Incluir um contato novo

void incluir() {
    if (total >= MAX) {
        printf("Agenda cheia!\n");
        return;
    }
    printf("Nome: ");
    scanf(" %[^\n]", agenda[total].nome);
    printf("Telefone: ");
    scanf(" %[^\n]", agenda[total].telefone);
    total++;
    printf("Contato incluido!\n");
}

Passo a passo do que acontece quando você escolhe "incluir":

  • Primeiro ele checa se a agenda está cheia. Se já tem 100, avisa e para.
  • Depois pergunta o nome e o telefone, e guarda na próxima gaveta livre.
  • total++ quer dizer "aumenta o contador em 1", porque agora tem um contato a mais.
Sobre o scanf: ele é o que "ouve" o que você digita no teclado e guarda na ficha. Aquele %[^\n] é só um truque para aceitar nomes com espaço (tipo "Maria Silva").

5 Listar todos os contatos

void listar() {
    int i;
    if (total == 0) {
        printf("Nenhum contato cadastrado.\n");
        return;
    }
    for (i = 0; i < total; i++) {
        printf("%d - %s | %s\n", i + 1, agenda[i].nome, agenda[i].telefone);
    }
}

Se não tiver ninguém cadastrado, ele avisa. Se tiver, o for funciona como "passar por todas as gavetas, uma por uma" e mostrar o nome e o telefone de cada contato na tela.

Analogia: é como folhear o caderninho do começo ao fim, lendo cada página em voz alta.

6 Consultar um contato pelo nome

void consultar() {
    char nome[50];
    int i, achou = 0;
    printf("Digite o nome: ");
    scanf(" %[^\n]", nome);
    for (i = 0; i < total; i++) {
        if (strcmp(agenda[i].nome, nome) == 0) {
            printf("Nome: %s\nTelefone: %s\n", agenda[i].nome, agenda[i].telefone);
            achou = 1;
        }
    }
    if (achou == 0) {
        printf("Contato nao encontrado.\n");
    }
}

Você digita o nome que procura. O programa passa por todos os contatos e, em cada um, usa o strcmp para comparar se o nome bate com o que você digitou.

  • Se achar, mostra o contato e marca achou = 1 (uma forma de dizer "achei!").
  • No fim, se achou continuar em 0, avisa que não encontrou.
Analogia: é como perguntar "alguém aqui se chama Maria?" e ir conferindo ficha por ficha.

7 Excluir um contato

void excluir() {
    char nome[50];
    int i, pos = -1;
    printf("Digite o nome: ");
    scanf(" %[^\n]", nome);
    for (i = 0; i < total; i++) {
        if (strcmp(agenda[i].nome, nome) == 0) {
            pos = i;
        }
    }
    if (pos == -1) {
        printf("Contato nao encontrado.\n");
        return;
    }
    /* puxa os contatos seguintes uma posicao para tras */
    for (i = pos; i < total - 1; i++) {
        agenda[i] = agenda[i + 1];
    }
    total--;
    printf("Contato excluido!\n");
}

Primeiro ele procura o contato (igual à consulta) e anota em qual gaveta ele está (pos). Se não achar, avisa e para.

A parte importante é o comentário: "puxa os contatos seguintes uma posição para trás". Quando você tira uma ficha do meio, fica um buraco — então o programa empurra todas as fichas seguintes uma casa para frente, para não sobrar espaço vazio. Depois, total-- diminui o contador em 1.

Analogia: é como tirar um livro do meio da prateleira e empurrar os outros para o lado, para não ficar aquele vão.

8 O menu — o "cérebro" do programa

int main() {
    int opcao;
    do {
        printf("\n=== AGENDA DE CONTATOS ===\n");
        printf("1 - Incluir contato\n");
        printf("2 - Listar contatos\n");
        printf("3 - Consultar contato\n");
        printf("4 - Excluir contato\n");
        printf("5 - Sair\n");
        printf("Opcao: ");
        scanf("%d", &opcao);

        switch (opcao) {
            case 1: incluir(); break;
            case 2: listar(); break;
            case 3: consultar(); break;
            case 4: excluir(); break;
            case 5: printf("Saindo...\n"); break;
            default: printf("Opcao invalida!\n");
        }
    } while (opcao != 5);

    return 0;
}

Essa é a parte principal, que junta tudo. Ela mostra o menu e pergunta qual opção você quer (de 1 a 5).

  • O switch é como um porteiro: olha o número que você digitou e chama a função certa (incluir, listar, etc.).
  • O do ... while (opcao != 5) faz o menu aparecer de novo e de novo, até você escolher a opção 5 (Sair).
  • Se você digitar um número que não existe no menu, o default avisa "Opção inválida!".
Analogia: é o balcão de atendimento da agenda. Ele pergunta o que você quer, te encaminha para o lugar certo, e volta a perguntar — até você dizer "tchau" (opção 5).

✅ Resumindo em uma frase

O programa guarda contatos numa "estante de gavetas" (o vetor), e um menu fica perguntando o que você quer fazer — anotar, ver a lista, procurar ou apagar — repetindo até você escolher sair. Simples assim! 🎉
